앱

서버의 유무
	필요한 경우: 회원가입 여러 기기에서 데이터 동기화, 게시글 작성등이 필요한 경우
		( 앱 ->  (인터넷 통신) 클라우드 서버 -> 데이터 베이스 )
	필요하지 않는 경우: 간단한 계산기, 오프라인 메모장같이 내부 저장공간을 활용하는 것
		( 앱 -> 스마트폰 내부 저장 공간 )

개발 앱
	vs 코드 : 주로 쓰는 앱
	android studio : 예전에 한 번은 써봤고 이미 다 까먹음
	flutter : 안드로이드 통해 써봤고 dart라는 언어 공부해야함

서버가 필요한 앱 이라면 선택할 수 있는 경로
	역할				사용할 수 있는 기술
											
	앱 화면			Flutter + Dart

	백엔드 서버		Python FastAPI 또는 Java Spring

	데이터베이스		PostgreSQL

	백엔드 관리 서비스	Firebase 또는 Supabase

배포 위치
	Android: Google Play 스토어
	iOS: 애플 스토어

배워야 할 언어
	Dart
	Flutter
	API 통신
	데이터베이스와 SQL
	백엔드 기초(Python 또는 Java)

장점 - 배포를 유명하기도 하고 사람들이 많이 쓰는 곳에서 그리고 벡엔드의 기초를 다지며 나의 맨 처음 목표와 같다
단점 - 벡엔드의 기초 말그대로 기초이며 따로 후에 더 배워야 할 가능성이 크다 그리고 원래의 코드 언어가 아닌 새로배우는 코드가 대부분이다

보류로 두고 싶다 이것도 웹과 비슷하게 하고싶은 것 중 한개이다
근거로는 시간만 많았다면 앱 개발을 하고 웹 개발을 하고 게임 개발 이렇게 3개를 순서대로 하고싶다 그게 순차적이고 그게 쉬움에서 점점 어려움으로 가는 것 같아서이다 하지만 2학년 때도 무지하게 바쁠 예정이라서 일단은 더 많이 배울 수 있는 웹을 [1] 앱을 [2]로 두고싶다

웹사이트

개발 앱
	vs 코드 : 전에 썼으며 익숙함

서버 운영
	간단한 웹 사이트: 자기소개 페이지, 포트폴리오, 단순 정보 사이트
		( 사용자의 브라우저 -> 웹사이트 파일이 저장된 호스팅 )
	기능이 있는 웹 서비스: 회원가입필요, 게시판, 댓글, 검색, 상품관리
		( 사용자의 브라우저 -> 프론트,백엔드 서버 -> 데이터 베이스 )

배포 위치 
	대표 적인 서비스 3개 : vercel, supabase, github
	Vercel: 웹사이트와 백엔드 배포
	Supabase: 데이터베이스, 로그인, 파일 저장 등
	GitHub: 코드 저장 및 배포 연결
	
	예를 들어 GitHub에 코드를 올리고 Vercel과 연결하면 코드 변경 사항을 자동으로 배포하는 방식으로 운영할 수 있어. Supabase는 PostgreSQL 데이터베이스와 로그인, 파일 저장 등의 기능을 제공해 ( ai의 설명 )

배워야 할 언어 ( 미래에 할 벡엔드 개발과 연결하기 좋은 분야 )
	html
	css
	javascript
	react 또는 next.js
	python fastapi 또는 java spring ( 벡엔드를 직접 만든다면 )
	sql 

장점 - 요즘은 벡엔드 시장이 좋다해서 벡엔드를 배우고 싶었는데 직접 만들 수 있는 기회가 생기고 특히 원래 배웠던 코드가 사용된다 학교에서도 배웠고 학교 책도 있다
단점 - 보통 사람들이 사용하지 않는 장소에서 배포하며 sql도 dml만 배우고 sqld도 없기에 아직은 배울 때 어려울 점이 많이 생겨보인다 처음 보는 코드 언어도 있어보인다

우선순위로 두고 싶은 웹 개발 이며 아이디어만 있다면 지금 당장 시작하고 싶다
근거로는 벡엔드를 배우고 싶은데 벡엔드를 배우기 좋은 환경과 포트폴리오에도 도움이 될 것 같아서다 그리고 이걸 하면서 자격증을 딸 수도 있을 것 같다는 생각이 들었다 예시를 들면 sqld같은 것을 많이 어려울지 몰라도 해보고 싶다

게임 ( 직접 플레이 하는 게임 ) ( 최대한 배제 )

개발 앱 ( 대표적인 게임 엔진 )
	godot : GDScript 또는 C#, 2D 및 3D 게임 개발, 비교적 가볍고 무료로 시작하기 좋음
	unity : C#, 2D 및 3D 게임 개발, 다양한 플랫폼으로 게임 배포 가능
	HTML + CSS + JavaScript : 
		브라우저에서 실행되는 게임, Canvas를 이용한 화면 그리기, 별도의 게임 엔진 없이도 개발 가능
	
서버 운영
	싱글 게임 : 인터넷 서버 없이도 가능한 경우
		( 사용자 컴퓨터 또는 스마트폰 )
	온라인 게임 : 인터넷이 있어야 하는 경우
		( 플레이어 다수 <-> 게임 서버 <-> 데이터 베이스 )

배포 위치 
	pc 게임: steam등의 게임 배포 플랫폼
	웹 게임: vercel 등의 웹 호스팅
 	모바일 : goole play 스토어, 애플 스토어

배워야 할 언어
	GDScript 또는 C#
	게임 엔진 사용법
	자료구조와 알고리즘
	게임 루프와 렌더링
	물리 및 충돌 처리
	온라인 게임이라면 네트워크 통신과 서버 개발

장점 - 아예 처음부터 배운다 조금 배우고 시작하는 것 보다 처음 시작하는게 더 좋다고 생각하는 입장이였기에 처음 시작이 좋게 보였다 배포 위치도 익숙하고 좋다
단점 - 심각할 정도로 처음이다 모든 코드를 처음 보고 상대의 움직임 나의 움직임 공격 방식 등 챙길게 많고 특히 온라인이라면 서버를 열고 더 어렵게 될 가능성이 높다 스토리 + 게임 운영 + 게임 작동 방식 등 챙길게 너무 많은데 아예 초짜이기에 어려워 보인다

게임 개발을 최대한 후 순위로 밀고 싶고 만약 다른 걸 개발 후 기회가 된다면 해보고 싶다
후순위의 근거로는 최근 c#이 안좋게 보이며 실제로 보안인가 뭔가가 뚫렸다고 들렸고 처음 배우는게 무섭다 다른 웹/앱 개발로 더 배우고 성장한 후에 좀 더 완성도있게 제작 하고 싶은 것인 게임 개발이다

	프론트엔드: 사용자가 직접 보고 조작하는 부분

	호스팅: 프로그램이나 서버를 인터넷에서 실행할 수 있도록 제공하는 환경

	최종 결과물의 형태 , 벡엔드 작성 유무
		실제로 내가 어디에 하고 싶은지 모바일 앱, 인터넷 웹 사이트, pc에 설치하는 프로그램, 조작하는 게임 그리고 백엔드까지 내가 직접 만들고 싶은지 예를 들어 Python이나 Java로 서버를 직접 만들고 데이터베이스까지 연결하는 것
